Using the API

The API provides access to proxy users, live status, and log levels. The admin interface uses a secure session cookie; sign-in and password changes have dedicated endpoints. Trusted backend services can use PROXY_API_TOKEN on endpoints that support service-token authentication. Never expose a service token in browser code. Proxy credential verification and disconnect endpoints use the proxy user's own credentials.
