Adgang

API-base: https://vpn.homerouter.io/api/v1

Bruger admin-siden med den sikre session-cookie, eller send Authorization: Bearer <token> fra et betroet backend-system.

Service-tokenet konfigureres som PROXY_API_TOKEN på proxyen, skal være mindst 32 tegn og er ikke beregnet til browserkode. Uden token bruger server-til-server-klienter admin-login og session-cookie.

Efter første admin-login skal bootstrap-passwordet skiftes, før brugeradministration er tilladt.

Alle JSON-requests bruger Content-Type: application/json. Fejl returneres som {"error":"..."}. Passwords skal være mindst 12 tegn.

Docker-logniveau

GET /api/v1/settings/logging viser det aktive niveau. PATCH /api/v1/settings/logging med {"level":"DEBUG"} ændrer det straks og gemmer valget til genstart.

Gyldige niveauer: DEBUG, INFO, WARNING, ERROR. Loglinjer indeholder bruger, remote IP, target host, status, bytes og varighed; passwords, auth-headere, URL paths og request bodies logges ikke.

Følg Docker-output med docker compose logs -f vpn-proxy.

Proxyoversigten opdaterer live-brugere og forbindelser hvert femte sekund. En bruger tælles kun, mens en HTTP-request behandles eller en CONNECT-tunnel er åben; det er ikke en vedvarende login-session.

Afbryd proxyforbindelser

Extensionens AFBRYD TUNNEL sender proxy-brugernavn og -password over HTTPS til POST /api/v1/proxy/disconnect. Serveren annullerer alle aktive requests og tunneler for brugernavnet. Hvis samme bruger er sat op på flere enheder, afbrydes de alle.

Et tvunget browser-/OS-stop kan ikke sende afbrydelsesbeskeden; TCP-forbindelserne lukker i stedet ved normal socket-oprydning.

Verificér proxy-login

Extensionen kontrollerer brugernavn/password direkte mod POST /api/v1/proxy/verify over HTTPS, før den tester proxytrafikken. Det omgår Chrome's cachede proxy-auth; du behøver ikke genstarte browseren efter credential-ændringer.

Endpointet returnerer kun om login er gyldigt og opretter ikke en session.

Eksempel: opret bruger

curl --request POST \
  --url https://vpn.homerouter.io/api/v1/users \
  --header 'Authorization: Bearer <PROXY_API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{"username":"service-user","password":"<12+ character secret>"}'
